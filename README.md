# Таймер Обратного Отсчета

Простое и элегантное веб-приложение таймера обратного отсчета, которое показывает оставшееся время до определенной даты. Этот проект отличается чистым, современным дизайном с плавными анимациями и адаптивной версткой.

## 🚀 Возможности

- **Обратный отсчет в реальном времени**: Обновляется каждую секунду, показывая дни, часы, минуты и секунды
- **Чистый интерфейс**: Современный минималистичный дизайн с эффектами при наведении
- **Адаптивность**: Работает на настольных и мобильных устройствах
- **Автоматическая остановка**: Таймер останавливается, когда отсчет достигает нуля
- **Нулевое дополнение**: Числа форматируются с ведущими нулями для единообразного отображения

## 📅 Текущая Цель Обратного Отсчета

Таймер настроен на отсчет до: **30 июня 2025 года 00:00:00**

## 🚀 Начало Работы

### Требования

- Современный веб-браузер (Chrome, Firefox, Safari, Edge)
- Дополнительное программное обеспечение не требуется

### Установка

1. Клонируйте или скачайте этот репозиторий
2. Откройте `index.html` в вашем веб-браузере
3. Таймер обратного отсчета запустится автоматически

### Локальный Запуск

Просто откройте файл `index.html` в любом современном веб-браузере. Обратный отсчет начнется немедленно.

## 🎨 Настройка

### Изменение Даты Обратного Отсчета

Чтобы изменить целевую дату, отредактируйте переменную `countdownDate` в `script.js`:

```javascript
let countdownDate = new Date("Jun 30, 2025 00:00:00").getTime();
```

Замените строку даты на желаемую целевую дату в формате: `"MMM DD, YYYY HH:MM:SS"`

### Настройка Стилей

Визуальный вид можно настроить, изменив `style.css`:

- **Цвета**: Измените цвета фона, текста и эффекты при наведении
- **Макет**: Настройте отступы, размеры и позиционирование
- **Анимации**: Измените эффекты переходов и состояния при наведении
